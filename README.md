# Year 9 Geography skills

Six interactive Year 9 Geography lessons (Changing places and Human wellbeing): line graphs,
column graphs, data tables, choropleth maps and evaluation writing.

Open `index.html`, or the live site on GitHub Pages. These are the student copies: the teacher
notes are kept out of this repository. They are generated by `build/build_site.py` in the
teacher's lesson folder, so edit the lessons there rather than here.

Data: World Bank (CC BY 4.0), Australian Bureau of Statistics (CC BY 4.0), UNDP Human Development
Report 2025, Natural Earth (public domain). Fonts: Lexend and Atkinson Hyperlegible (SIL OFL).
